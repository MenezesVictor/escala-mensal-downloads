# Escala Mensal — downloads oficiais

Os aplicativos aprovados ficam em **Releases**. Este repositório não contém o código do aplicativo, cadastros nem backups de paróquias.

No Windows, extraia o pacote de atualização antes de abrir o executável. A edição da 6.1 com atualizador oferece as próximas versões estáveis quando você abrir o aplicativo. Não é necessário entrar no GitHub. No Mac Apple Silicon, baixe o pacote manualmente.
